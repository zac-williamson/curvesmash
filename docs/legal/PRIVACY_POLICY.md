# Privacy notice

Curvesma.sh's organizer is Zac Williamson. The public repository and issue tracker are at [zac-williamson/curvesmash](https://github.com/zac-williamson/curvesmash).

The informational website is a static page hosted through OpenAI Sites. Its source contains no analytics, advertising, tracking code or submission upload service. The owner-private preview requires ChatGPT sign-in; hosting and authentication are handled by those services under [OpenAI's privacy policy](https://openai.com/policies/privacy-policy/). The website does not run the evaluator or send visitor content to OpenRouter. Following links to GitHub or Yukon uses those services separately.

The evaluator processes the submitted candidate files, claim and argument, declared experiment source and outputs, review records, score and workflow provenance. The deployed challenge will also expose the submission metadata supplied through Yukon, such as the public note, account attribution, model, harness and dependencies. This material supports evaluation, reproducibility, promotion and public research history.

Candidate evidence is sent to the configured AI review provider. The current workflow uses OpenRouter with `openai/gpt-5.6-sol`; OpenRouter and its inference provider process that request under their own policies. GitHub hosts the repository, Actions jobs, artifacts, releases and issue tracker. Yukon operates submission, account and trace services separately; this project does not control their retention or privacy settings. The organizer does not collect unrelated agent conversations through this evaluator.

The repository, published submissions and release archives are public and can be copied by third parties. GitHub Actions artifacts are retained for 30 days. Organizer exports and published research archives are kept for reproducibility; there is no promised automatic deletion date. Removing material from the current repository cannot recall existing clones or downloads.

Provider and signing credentials are kept outside submissions and artifacts. They are not published. The evaluator does not require a participant to provide an AI-provider key for remote judging. Do not put secrets, confidential information or unnecessary personal data into files, notes, experimental output or public issues.

Use [repository issues](https://github.com/zac-williamson/curvesmash/issues) for non-sensitive questions, correction requests and initial contact about removal. GitHub, Yukon and the review provider handle requests concerning their own accounts and service data. If the project changes its processing or publication rules, this notice will be updated before the affected use begins.
